# octave-prey-predator-automaton
Voor dit project bouwen we een cellulaire automaton op basis van het prooi-predatormodel (prey-predator). Het doel hiervan is om met behulp van GNU Octave meer inzicht te krijgen in de werking van cellulaire automaton. We hebben een week de tijd om aan dit project te werken, waarna we het eindresultaat zullen presenteren. 
Het prooi-predatormodel is gebaseerd na de volgende principes: 
- Er zijn minstens twee organismen aanwezig: organisme A (de prooi) en organisme B (het roofdier), waarbij organisme B jaagt op organisme A. 
- Bij een overpopulatie van organisme B neemt het aantal roofdieren af door voedseltekort. 
- Bij een overpopulatie van organisme A neemt het aantal prooien af door een tekort aan natuurlijke hulpbronnen (zoals gras). 
Deze dynamiek zorgt ervoor dat de populatiegrootten van beide organismen continu fluctueren.
